# OpenStrike

Open-source tactical FPS built from original code, gameplay systems,
maps, assets, audio, and visual identity.

## Project goals

OpenStrike is an original tactical FPS inspired by the classic
round-based competitive shooter genre.

The project does not use proprietary Counter-Strike code, maps,
models, textures, sounds, logos, or other copyrighted game assets.

## Planned systems

- First-person movement
- Mouse look
- Tactical shooting
- Weapons and recoil
- Ammunition and reload
- Teams
- Round system
- Economy and buying
- Objectives
- Bomb/defusal gameplay
- Bots
- LAN multiplayer
- Dedicated server
- Original maps
- Original audio and visual assets
- Windows and Linux support
- Modding support

## Engine

Godot 4
